# Meta Global AI Developer Hackathon · hand-in checklist

The event instructions shared by the organizer specify four submission items and a deadline of **Wednesday, November 4, 2026 at 9:00 PM ET**. For Istanbul (UTC+3), that is **Thursday, November 5 at 5:00 AM**. Submit earlier than the cutoff and recheck the official platform in case organizer instructions change.

## Required hand-in

- [ ] Submit through the Cerebral Valley hackathon submission page.
- [ ] Add every actual teammate to the submission. This is a solo project; do not invent teammates.
- [ ] Upload a finished demo video no longer than three minutes. See [DEMO_SCRIPT.md](DEMO_SCRIPT.md).
- [ ] Include the public GitHub repository URL and confirm it opens in a logged-out browser.
- [ ] Review every required field and submit before the deadline; capture the confirmation screen/email.

## Before sharing the repository

- [ ] Confirm GitHub visibility is **Public** and the root README explains setup and demo limits.
- [ ] Confirm `.env` and any key files are ignored; never stage or paste the Meta API key.
- [ ] Keep `.env.example` blank and disabled by default.
- [ ] Remove temporary downloads, screenshots, private photos, generated credentials, and unrelated files from the staged changes.
- [ ] Confirm the demo's sample scene and action counts are clearly labeled; role switching is simulated; live findings are candidate observations, not safety assessments.
- [ ] Show the renter-specific room card: ask permission before drilling or changing fixtures, and use practical interim checks.
- [ ] Confirm the submission URL, video, and repository all work from a clean logged-out session.

## Final five-minute check

- [ ] Video opens, has audio, shows the product working, and is at most 3:00.
- [ ] Public repository opens without sign-in.
- [ ] Submission preview has the right project name, solo team details, video, and repository URL.
- [ ] Submission is marked received before leaving the platform.
