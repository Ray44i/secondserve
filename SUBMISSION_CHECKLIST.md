# SecondServe submission checklist

- [ ] `npm test` passes on the final commit.
- [ ] App starts locally and the recovery workflow works end-to-end.
- [ ] Three-minute video uses the final project and demonstrates cancellation recovery plus coordinator-verified impact.
- [ ] Public GitHub repository opens in a logged-out browser; `.env`, API keys, local database, and personal data are absent.
- [ ] Submission text describes demo fixtures, simulated notifications, and the model's draft-only role honestly.
- [ ] CV platform submission includes every teammate (solo entry: the builder's account), video, and public repository URL.
- [ ] Final deadline reconfirmed in the live event portal and submission completed ahead of it.
