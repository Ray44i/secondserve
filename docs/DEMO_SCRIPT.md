# SecondServe demo script

“Surplus food is time-sensitive. A match only helps if a verified recipient can collect it. SecondServe checks a reported batch against partner constraints, explains a shortlist, and recovers when the first partner cancels.”

Load the recovery scenario as coordinator. Run the decision agent, show the eligibility checks and exclusions, then dispatch. Switch to Charity A, accept and cancel. Return to coordinator: show released capacity, the recovery event, and the new offer to Community Kitchen B. Accept as Kitchen B and report a pickup. Show the quantity is still unverified. Verify a quantity as coordinator and show the verified ledger, grouped by unit.

Close with the review scenario and disclose that the recipient records, coordinates, capacities, availability, and offer notifications are fictional/simulated. Muse Spark can draft text intake only after an explicit action; it does not verify food safety.
