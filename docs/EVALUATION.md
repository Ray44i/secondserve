# Evaluation plan

Automated domain tests cover candidate eligibility, weighted ranking, capacity reservation, duplicate acceptance rejection, cancellation recovery, safety holds, use-by vs best-before handling, pickup verification, and impact unit grouping. Run `npm test`.

A successful test run validates code paths only. It does not establish that food-safety rules are legally sufficient, model extraction is accurate, partners are available, logistics estimates are real, environmental impact is positive, or the app is production-secure. For a credible product evaluation, collect consented real-world cases and have qualified food-rescue operators review constraints and outcomes before deployment.
